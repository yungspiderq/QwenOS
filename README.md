# WebOS — операционная система на HTML

Полностью браузерная демо-ОС на чистом **HTML + CSS + JavaScript** (без зависимостей и сборки).

## Запуск
Просто откройте `index.html` в браузере, либо запустите локальный сервер:
```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Возможности
- 🚀 Экран загрузки → 🔐 экран блокировки/входа → 🖥 рабочий стол
- 🪟 Оконный менеджер: перетаскивание, изменение размера, свернуть/развернуть/закрыть, фокус, панель задач
- 📁 Виртуальная файловая система (сохраняется в `localStorage`)
- 💻 Терминал с командами: `help, ls, cd, pwd, cat, echo, touch, mkdir, rm, clear, date, whoami, uname, tree, neofetch, open, bsod`
- 📝 Приложения: Блокнот, Калькулятор, Проводник, Рисовалка, Сапёр, Игра «Жизнь», Часы, Браузер, Настройки, О системе, Корзина
- 🎨 Смена обоев, виджет часов, уведомления со звуком, контекстные меню, шутливый BSOD
- ⌨️ Горячие клавиши: `Ctrl+Alt+T` — терминал, `Esc` — закрыть меню

## Файлы
| Файл | Назначение |
|---|---|
| `index.html` | Разметка: загрузка, логин, рабочий стол, панель задач |
| `style.css` | Все стили системы и приложений |
| `apps.js` | Файловая система и реестр приложений |
| `os.js` | Ядро: оконный менеджер, меню Пуск, уведомления и т.д. |
