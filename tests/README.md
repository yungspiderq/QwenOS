# Тесты QwenOS

- `smoke.js` — смоук-тест в jsdom: загрузка, вход, монтирование всех приложений,
  команды терминала, ФС, парсер калькулятора, оконный менеджер.
  Запуск: `npm i jsdom && node tests/smoke.js`
- `inter.py` — 23 интеракционных сценария в реальном Chromium (Playwright):
  перетаскивание и ресайз окон, dblclick-максимизация, контекстные меню, Tab-дополнение
  в терминале, сохранение из блокнота, клики калькулятора, игры, установка из магазина,
  яркость, обзор окон, рисование в Paint, навигация QwenNet, блокировка экрана.
  Запуск: `pip install playwright && playwright install chromium && python3 tests/inter.py`
